## Enfoque

El formato activo ya no es resumen semanal ni interfaz ligera. Ahora el material principal esta en libros largos en HTML, pensados para lectura profunda, reproduccion de codigo y estudio lento.

## Como estudiar esto

1. Lee un capitulo completo sin saltar secciones.
2. Reescribe a mano todo el codigo.
3. Haz los ejercicios largos al final de cada capitulo.
4. No avances hasta poder explicar el capitulo anterior sin mirar.
